# Official Airflow reference

This project builds from Apache Airflow 2.10.5. Check that version before applying guidance from https://github.com/apache/airflow or https://airflow.apache.org/docs/apache-airflow/2.10.5/ . Distinguish 2.x APIs from the newer 3.x SDK and public API. Confirm recommendations against the installed DAGs and Docker image before editing them.

The Apache repository is source code and documentation, not a standalone skill to clone into a skills directory. This local skill directs the agent to the matching official reference and preserves the project's existing orchestration design unless a change is requested.
